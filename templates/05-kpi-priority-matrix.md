# Template: KPI Priority Matrix (2×2)
Materiali di supporto al libro "[Sustainable IT the Right Way](https://leanpub.com/sustainable-it)" di Francesco Fullone.

*Riferimento: Capitolo 4, Esercizio #4A*

## Scopo

Selezionare i KPI che finiscono nella dashboard, filtrando il rumore e le vanity metrics.

## Matrix

```
          ALTO Impatto (Business/Planet)
            │
    FOCUS   │  STRATEGIC (Top 5-7)
 (Monitor)  │  (Dashboard Executive)
            │
────────────┼────────────────────────
            │
    KILL    │  QUICK WIN
 (Vanity)   │  (Team Operativo)
            │
          BASSO Impatto

 BASSO ───── Actionability ───── ALTO
```

## Come usarlo

Posiziona ogni potenziale metrica nei quadranti:

1. **Strategic** (Alto Impatto, Alta Actionability): Vanno nella dashboard executive. Es. *Carbon Intensity per Transazione (SCI)*.
2. **Quick Win** (Basso Impatto, Alta Actionability): Utili per i team operativi. Es. *% Codice coperto da Green Linter*.
3. **Focus/Monitor** (Alto Impatto, Bassa Actionability): Da osservare, ma non guidano decisioni immediate (spesso Lagging Indicators). Es. *Total Carbon Footprint annuale*.
4. **Kill** (Basso Impatto, Bassa Actionability): Vanity metrics da eliminare. Es. *Numero di server spenti (senza contesto)*.
