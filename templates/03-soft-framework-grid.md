# Template: SOFT Framework Grid
Materiali di supporto al libro "[Sustainable IT the Right Way](https://leanpub.com/sustainable-it)" di Francesco Fullone.

*Riferimento: Capitolo 3, Esercizio #3 "SOFT Pillar Quick Check"*

## Scopo

Mappare iniziative sostenibilità esistenti ai 4 pilastri SOFT, identificare coverage gap (pilastri con poche iniziative).

## Grid

Quattro quadranti (2×2):

```
┌─────────────────────────┬─────────────────────────┐
│   STRATEGY              │   IMPLEMENTATION        │
│                         │                         │
│ -                       │ -                       │
│ -                       │ -                       │
│ -                       │ -                       │
│                         │                         │
│ Coverage: __/__ (__%)   │ Coverage: __/__ (__%)   │
├─────────────────────────┼─────────────────────────┤
│   OPERATIONS            │   COMPLIANCE            │
│                         │                         │
│ -                       │ -                       │
│ -                       │ -                       │
│ -                       │ -                       │
│                         │                         │
│ Coverage: __/__ (__%)   │ Coverage: __/__ (__%)   │
└─────────────────────────┴─────────────────────────┘
```

## Come compilarlo

1. **Elenca tutte le iniziative sostenibilità** in corso o pianificate (brainstorming, 10 minuti)
2. **Per ogni iniziativa**, assegna a uno dei 4 pilastri SOFT:
   - **Strategy**: Governance, policy, OKR, training
   - **Implementation**: Tool, automazione, infrastructure as code
   - **Operations**: Monitoring, alerting, continuous improvement
   - **Compliance**: Reporting, audit, regulatory
3. **Calcola coverage**: Numero iniziative per pilastro / Totale iniziative
4. **Identifica gap**: Pilastri con < 20% coverage sono critici
5. **Azione**: Per pilastri gap, identifica 2-3 iniziative quick win da aggiungere
