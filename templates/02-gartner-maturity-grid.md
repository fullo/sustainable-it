# Template: Gartner Maturity Grid
Materiali di supporto al libro "[Sustainable IT the Right Way](https://leanpub.com/sustainable-it)" di Francesco Fullone.

*Riferimento: Capitolo 2, Esercizio #2 "Maturity Self-Assessment"*

## Scopo

Valutare maturità attuale su 5 dimensioni (Govern, Plan, Measure, Reduce, Engage) e identificare gap rispetto a livello target.

## Grid

Matrice 5 dimensioni × 5 livelli = 25 celle:

```
              L1: Aware   L2: Act   L3: Achieve   L4: Advance   L5: Amplify
┌──────────────┼───────────┼─────────┼─────────────┼─────────────┼─────────────┐
│ GOVERN       │           │         │             │             │             │
│ PLAN         │           │         │             │             │             │
│ MEASURE      │           │         │             │             │             │
│ REDUCE       │           │         │             │             │             │
│ ENGAGE       │           │         │             │             │             │
└──────────────┴───────────┴─────────┴─────────────┴─────────────┴─────────────┘
```

## Come compilarlo

1. **Per ogni dimensione**, rispondi alle 3 domande di assessment (Capitolo 2, sezione 2.4)
2. **Calcola score** per dimensione: somma punti (1-5 per domanda)
3. **Posiziona "X"** sulla grid al livello corrispondente
4. **Identifica gap**: Delta tra livello attuale e target
5. **Prioritizza**: Quale dimensione migliorare per prima? (usa matrice effort/impact)

## Interpretazione score

| Livello | Score range | Caratteristiche | Prossimo step |
|---------|-------------|-----------------|---------------|
| **L1: Aware** | 3-5 punti | Awareness iniziale, no processi | Creare governance committee |
| **L2: Act** | 6-10 punti | Approccio sistematico, primi processi | Baseline metrics |
| **L3: Achieve** | 11-13 punti | Processi standardizzati, governance | Automation, tool integration |
| **L4: Advance** | 14 punti | Metrics-driven, ottimizzazione | Continuous improvement |
| **L5: Amplify** | 15 punti | Thought leadership, ecosystem influence | Industry evangelism |
