# Template: Piano 90 Giorni
Materiali di supporto al libro "[Sustainable IT the Right Way](https://leanpub.com/sustainable-it)" di Francesco Fullone.

*Riferimento: Capitolo 12, Sezioni 12.3 (piano dei 90 giorni), 12.4 (checklist del lunedì mattina), 12.5 (gestire il Dip)*

## Scopo

Trasformare il piano generico dei primi 90 giorni del libro in una roadmap personale con date, owner e numeri attesi. Non si presenta a nessuno: si esegue. Regola d'oro: ogni fase ha un obiettivo unico, non anticipare la fase 3 nel primo mese.

## Struttura

```
 MESE 1 — VISIBILITÀ      MESE 2 — STRUTTURA        MESE 3 — OPERATIVITÀ
 (Awareness)              (Strategy)                (Implementation)
 ────────────────────    ─────────────────────     ──────────────────────
 S1  Baseline grezza      S5  Comitato (Cap 10)      S9  Processi/CI-CD (Cap 7)
 S2  Maturity (Cap 2)     S6  Primo OKR (Cap 4)      S10 Formazione (Cap 9)
 S3  Caccia al Tesoro     S7  Alleanze (Cap 9)       S11 Revisione dati
 S4  Primo Strike         S8  Procurement (Cap 5)    S12 Report interno (Cap 11)

 ┌── CASELLE TRASVERSALI (reggono tutto il piano) ────────────────────────┐
 │ Commitment card (l'azione di lunedì)  ·  Il mio alleato (Cap 9)         │
 │ Piano anti-Dip (contromisura al flesso di fine Mese 2, Cap 1 + Cap 10)  │
 └────────────────────────────────────────────────────────────────────────┘
```

## Worksheet — le 12 settimane

Ogni settimana ha un doppio campo: **Output** (cosa produci) e **Outcome** (quale valore crei). Compila data, owner e almeno un numero atteso.

| Sett. | Azione | Output | Outcome | Data | Owner | Numero atteso |
|-------|--------|--------|---------|------|-------|---------------|
| 1 | Baseline (tool cloud + inventario) | | | | | ___ ton CO2e/anno |
| 2 | Maturity Assessment (Cap 2) | | | | | punteggio + gap |
| 3 | Caccia al Tesoro (quick win) | | | | | 3 candidati |
| 4 | Primo Strike (esegui 1 azione) | | | | | € ___ /anno |
| 5 | Comitato / Task Force (Cap 10) | | | | | 3-5 membri |
| 6 | Primo OKR del trimestre (Cap 4) | | | | | 1 Objective |
| 7 | Alleanze fuori dall'IT (Cap 9) | | | | | 2 alleati |
| 8 | Clausola Procurement (Cap 5) | | | | | 1 RFP/rinnovo |
| 9 | Check nei processi/CI-CD (Cap 7) | | | | | 1 team pilota |
| 10 | Workshop Green Software (Cap 9) | | | | | ___ partecipanti |
| 11 | Revisione dati vs baseline | | | | | - ___ % vs S1 |
| 12 | Report interno 1 pagina (Cap 11) | | | | | € e ton CO2e |

## Worksheet — le 3 caselle trasversali

| Casella | Campo da compilare |
|---------|--------------------|
| **Commitment card** (§12.4) | La mia azione di lunedì mattina: _______________ — dove attacco il post-it: ___________ |
| **Il mio alleato** (Cap 9) | Nome e ruolo: ___________ — perché la sostenibilità aiuta i SUOI obiettivi: ___________ |
| **Piano anti-Dip** (§12.5) | Il numero che mostrerò (risparmio Primo Strike): € ___ — la decisione che porto al Comitato se mi blocco: ___________ |

## Domande guida

1. **Ogni settimana compilata ha SIA un Output SIA un Outcome?** Output senza Outcome è attivismo; Outcome senza Output è fortuna.
2. **Almeno 3 slot hanno un numero atteso**, non solo testo? (baseline, risparmio, partecipanti)
3. **Hai identificato il tuo "Marco" o la tua "Sara"** — l'alleato interno che sblocca le porte?
4. **Hai un piano per il "Dip" del secondo mese?** La contromisura non è più motivazione: sono i soldi risparmiati e la struttura del Comitato.
5. **Verifica finale (domanda socratica del Cap 12):** se tra 90 giorni ti chiedessero "cosa hai fatto per la sostenibilità IT?", la risposta contiene già almeno 2 numeri (guardando le settimane 1, 4, 11 e 12)?
