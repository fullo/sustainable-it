# Template: RACI Matrix
Materiali di supporto al libro "[Sustainable IT the Right Way](https://leanpub.com/sustainable-it)" di Francesco Fullone.

*Riferimento: Capitoli 10, 11*

## Scopo

Definire accountability chiara per iniziative sostenibilità. Evitare il "tutti responsabili, nessuno accountable".

## Matrix

```
R = Responsible (chi fa il lavoro)
A = Accountable (chi risponde del risultato — UNO solo per riga)
C = Consulted (chi viene consultato prima di decidere)
I = Informed (chi viene informato dopo la decisione)
```

## Regole di validazione

Per ogni riga della matrice, verifica:

- [ ] Esattamente **UNA** "A" (Accountable) per riga
- [ ] Almeno **UNA** "R" (Responsible) per riga
- [ ] Non troppi "C" (Consulted) — rallentano le decisioni
- [ ] Ogni colonna ha almeno un ruolo — nessuno è "spettatore puro"

## Anti-pattern comuni

| Anti-pattern | Problema | Soluzione |
|--------------|----------|-----------|
| Tutti "A" | Nessuno è davvero accountable | Scegliere UN solo A |
| Nessun "R" | Nessuno fa il lavoro | Assegnare almeno un R |
| Troppi "C" | Decisioni lente, committee-driven | Max 2 C per riga |
| A senza autorità | L'accountable non ha potere decisionale | A deve avere budget/authority |
